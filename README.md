# Microsoft Data Analysis with SQL, Excel & Power BI

## Overview

Completed the **Microsoft Data Analysis with SQL, Excel & Power BI Specialization** through Coursera.

This five-course specialization provided hands-on exposure to the end-to-end data analytics workflow, covering SQL, SQL Server, Microsoft Excel, Copilot in Excel, and Power BI.

- Extracting data for analysis

### 2. Data Manipulation and Transactions in SQL Server

- SQL Server
- Transactions
- Working with relational data

### 3. Data Cleaning & Processing with Copilot in Excel
- Data cleaning
- Missing-data identification and handling
- Standardizing data
- Data formatting and organization
- Copilot-assisted data processing

### 4. Advanced Data Analysis & Visualization with Copilot in Excel
- Data analysis
- Pivot-based analysis
- Sales and performance analysis

### 5. Data Analysis and Visualization with Power BI
- Data visualization
- Interactive reports
- Tables and charts
- KPI analysis
- Sales trend analysis
- Forecasting
- Q&A / natural-language data analysis
- Business insights and reporting
